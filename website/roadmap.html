Roadmap

What's shipped, what's next

Pathly is built as working software first — this page tracks that honestly instead of promising a finished product. Priorities shift with feedback, so treat "Next up" as intent, not a committed date, and "Exploring" as ideas rather than promises.

Shipped

Working today, in the core app.

  • Multi-tenant organizations — create a new tenant or join one by code
  • Role-based access control (admin / teacher / student), enforced by Postgres Row Level Security
  • Courses, modules, and lessons
  • Enrollment — self-enroll plus teacher/admin roster management
  • Assignments, submissions, and grading with feedback
  • Announcements, scoped to an organization or a single course

Next up

The near-term priorities.

  • Native file uploads for submissions and course materials (Supabase Storage)
  • Discussion threads on courses
  • In-app notifications for grades, announcements, and due dates
  • SSO via SAML/OIDC for institutional identity providers

Exploring

Directions under consideration, not yet committed to.

  • SIS/institutional system connectors
  • Analytics and institutional reporting dashboards
  • LTI 1.3 support for third-party learning tools
  • Calendar sync (iCal/Google Calendar) for due dates and announcements
