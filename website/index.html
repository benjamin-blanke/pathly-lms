Pathly

An open-source LMS for institutions that need scale

Pathly is a modern, enterprise-grade alternative to platforms like itslearning — built for schools, universities, and organizations that need multi-tenancy, granular access control, and a codebase that scales beyond a single deployment.

View the project on GitHub

Multi-Tenant Architecture

Isolated instances for multiple schools and organizations from a single deployment.

Role-Based Access Control

Fine-grained permissions across students, teachers, admins, and institutional roles.

Courses & Modules

Structured learning paths with flexible content organization.

Assignments & Grading

Creation, distribution, submission, and grading workflows in one place.

Communication

Announcements scoped to your organization or a single course.

Security & Compliance

Built with data protection and auditability in mind, enforced at the database layer.
