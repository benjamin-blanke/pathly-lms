How it works

From sign-up to a running classroom in three steps.

01

Create or join an organization

Sign up, then spin up a brand-new tenant as its admin — or join an existing one with its organization code.

02

Build your courses

Teachers create courses, modules, and lessons, then open enrollment for students to join.

03

Teach, grade, communicate

Assign work, grade submissions with feedback, and keep everyone in the loop with scoped announcements.

Built to scale, not just to demo

A stateless app in front of a database that enforces the rules itself.

Frontend Next.js 16 App Router · Server Actions · Tailwind CSS
→
Auth Supabase Auth Email/password today · SSO-ready
→
Database Postgres + RLS Multi-tenancy & RBAC enforced at the data layer

One Next.js deployment can serve many tenants — every query is scoped by organization and role through Row Level Security policies, so isolation holds even if application code has a bug.
